# Precognition Plus documentation

Precognition Plus checks a FormRequest's simple rules in the browser and sends
only the fields with server rules to Laravel. Forms and FormRequests are
written the same way as with plain Precognition.

1. [Installation](installation.md)
2. [Usage guide](usage.md), with examples for Vue and React
3. [Rules](rules.md), which ones run in the browser and which go to the server
4. [How it works](how-it-works.md), request by request
5. [Limitations and troubleshooting](limitations.md)

The [live demo](https://precognition.codenyra.com) has a signup form with each
kind of field and a log of every check.
